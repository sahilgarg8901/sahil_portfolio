# sahil_portfolio

This repository hosts a **personal web portfolio** built with Flutter. The site
is inspired by [aura.build/s/sagarshende-portfolio](https://www.aura.build/s/sagarshende-portfolio)
and pulls details directly from the resume PDF located at
`assets/Sahil_Resume_Nov_2025.pdf`.

## Getting started

Run in a browser with:

```bash
flutter run -d chrome
```

Updates to the resume (assets PDF) and layout should be reflected in the UI; the
PDF is also downloadable from the header section.
